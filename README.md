# ☁️ 天翼云电脑全功能多账号可视化管理平台 (CtYun Web Dashboard)

本项目深度解析并融合了开源社区 **[leleji/CtYun](https://github.com/leleji/CtYun)**（C# 底层长连接保活）与 **[bytehola/ctyun-auto](https://github.com/bytehola/ctyun-auto)**（自动化日常任务脚本）的全部核心优势，通过深度逆向官方通信协议与底层视讯流握手序列，打造出的**现代化、高性能、超轻量、纯原生协议、零无头浏览器、零重型 AI 依赖**的企业级 Docker 应用。

---

## 🌟 核心突破与最新功能特性

### 1. 彻底拔除 Chromium 与重型依赖，镜像极度纯净
- **零无头浏览器**：彻底移除 Puppeteer 等臃肿环境，全部任务基于**毫秒级纯原生 HTTP / WebSocket 二进制协议直连**（耗时从 30 秒骤降至 300 毫秒），内存常驻仅 20MB~35MB；
- **零重型 AI 依赖**：完全移除 onnxruntime / jimp 等图形识别引擎（合计约 300MB），登录验证码改由**官方验证码图片人工输码**（100% 一次通过）；
- **Docker 镜像极致精简**：仅保留纯轻量原生 `ws` 协议库，构建与拉取秒级完成。

### 2. 破译官方底层视讯握手协议，杜绝「多 Session 互踢」
- **完整逆向天翼云 Clink 视讯流序列**：原生支持 Type 118（用户身份报文）、Type 112（会话凭证注入）、Type 104（通道挂接）及 Type 4/3/7 周期心跳握手；
- **官方任务中心 100% 真实达成**：无需网页模拟，官方直接确认「登录AI云电脑」达成（100 积分）与「使用1小时」时长真实累计（100 积分），轻松拿满每日 300 积分上限！

### 3. 智能分时保活引擎（挂机模式 + 脉冲模式自动切换）
- **挂机模式**（任务未达标）：持续维持长连接累加官方使用时长，按设定的「保活强制重连周期 (秒)」周期性刷新会话；
- **脉冲模式**（任务已达标）：每日 100 积分拿满后**立即主动释放独占通道**，之后按设定的「脉冲保活间隔 (分钟)」（默认 45 分钟，须小于 60 分钟）进行一次约 60 秒的短暂真实连接，重置天翼云「断开 1 小时自动休眠」计时器——机器全天保持唤醒，通道 99% 时间空闲；
- **从释放断开开始计时**：脉冲待机期间若检测到浏览器访问或官方手机 App / PC 客户端接入，脉冲计时**立即暂停并在其释放断开后从零重新计算**，绝不与真人抢线。

### 4. 会话失效智能告警（免 OCR 纯人工输码）
- **凭证持久化**：首次登录成功后 `secretKey / token` 等凭据加密持久保存，日常保活、打卡、AI 对话、挂机、商城兑换**全程零验证码**；
- **失效自动捕获**：凭据被天翼云强制过期时，系统立即停止无效重试（防风控），界面对应卡片亮起 `⚠️ 会话已失效` 红色告警；
- **Webhook 推送提醒**：通过企业微信 / Bark / Server酱 / PushPlus / Telegram 即时推送提醒，点击卡片 **「🔑 重新验证登录」**，看一眼官方验证码输入 4 位字符即可秒级恢复。

### 5. 主动关机自动保护与休眠自动唤醒
- **主动关机防误唤醒**：在控制台下达关机指令后自动关闭保活开关并打上保护标记，机器安心维持关机；
- **休眠自动唤醒**：云电脑被天翼云闲置策略休眠/关机时（非主动关机），后台自动下发官方电源指令（`operationType: 1`）自动唤醒，30 秒持续探测直至上线；
- **官方 App 开机自动接管**：无论在控制台、官方 App 还是官网开机，系统检测到机器启动后自动恢复保活守护。

### 6. 准时时间点调度系统（拒绝盲目轮询）
- **准点触发**：支持配置每日准时执行时间点（默认每天 `01:20`，支持多时间点 `01:20, 12:00`）；
- **分项 Cron 辅助规则**：高级模式可为签到 / AI 对话 / 挂机 / 兑换单独设定 Cron 表达式；未启用开关或未填写规则时严格以主调度时间点为准；
- **完成即休眠**：毫秒级准点触发，做完即标记今日达成，当天绝不再空转；支持重启补跑兜底。

### 7. 直通远程桌面与电源管理
- **一键直达桌面**：点击「🚀 访问云电脑」在独立窗口免密直达云电脑桌面，1:1 自适应本机分辨率，鼠标键盘精准无偏移，访问期间后台自动避让；
- **电源管理**：开机 / 重启 / 关机全指令支持，与保活状态智能联动。

## 🚀 极速部署指南

### 方式一：直接拉取预构建镜像（最推荐、飞牛 NAS / Docker 专用）

可以直接拉取官方 Docker Hub 镜像，也可以拉取 GitHub Packages 镜像：

```bash
# Docker Hub 镜像 (推荐国内 NAS 用户拉取)
docker run -d \
  --name ctyun-dashboard \
  -p 8080:8080 \
  -v $(pwd)/data:/app/data \
  --restart unless-stopped \
  learycn/ctyun-dashboard:latest
```

或使用 GitHub Packages (GHCR) 镜像：
```bash
docker run -d \
  --name ctyun-dashboard \
  -p 8080:8080 \
  -v $(pwd)/data:/app/data \
  --restart unless-stopped \
  ghcr.io/muyicn/ctyun-dashboard:latest
```

或使用 `docker-compose.yml` 部署：

```yaml
version: '3.8'
services:
  ctyun-dashboard:
    image: learycn/ctyun-dashboard:latest # 或 ghcr.io/muyicn/ctyun-dashboard:latest
    container_name: ctyun-dashboard
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
```

### 方式二：本地源码快速构建运行

1. 克隆代码库：
   ```bash
   git clone https://github.com/muyicn/ctyun-dashboard.git
   cd ctyun-dashboard
   ```

2. 启动服务：
   ```bash
   docker compose up -d --build
   ```

3. 访问系统：
   打开浏览器访问：**`http://你的服务器IP:8080`**
   - **默认管理员账号**：`admin`
   - **默认初始密码**：`admin123`
   *(首次登录后可随时在右上角头像菜单中修改管理员密码与用户名)*

## 🔒 账号与数据安全规范

1. **密码工业级加密落盘**：所有保存的天翼云账号密码均采用 **AES-256-GCM** 进行强加密后存盘，挂载目录即使被读取也无法还原明文；
2. **多租户权限严格隔离**：
   - 未登录访客完全阻断，无法窥探任何云电脑信息或控制台日志；
   - 普通注册用户仅能查看与操作自己名下的云电脑与专属日志；
   - 超级管理员（admin）拥有全局设备管理、用户与配额管控权限；
3. **SSRF 安全防御**：系统设置与 Webhook 推送严格校验目标地址，自动拦截本地回环、内网私有网段与非法协议。

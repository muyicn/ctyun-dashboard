🚀 版本更新说明 (v2.1.1)

✨ v2.1.1 重点特性与优化 (最新)
发布时间：2026-09-12
  • ⏰ 分项 Cron 独立调度解耦：分项 Cron 规则与主调度时间点彻底解耦，配置分项 Cron 后主时间点自动跳过对应分项，开机补跑按分项精准执行，绝不抢跑重复执行。
  • 🎁 单笔原子总积分兑换引擎：兑换多数量商品（如 10G 数据盘、30 天升配包）单笔直传总积分，云端原子化合并出单，彻底消除多件连续下单时的云端异步扩容锁定冲突。
  • 🎯 全品类奖项绑定规则对齐：升配包与数据盘扩容强制绑定云电脑，智库、云手机与游戏电脑直发型商品自动绑定手机号，不再误报未找到云电脑。
  • 🔑 管理员改名与防重建加固：按角色判定管理员存在性，管理员改名或删除后系统不再重复生成默认 admin，改名实时日志变量精准对应。
  • 👤 普通用户界面精简：头像下拉菜单按角色动态展示，普通用户仅显示修改密码与头像，隐藏管理员专有入口。
✨ v2.1 重点特性概览
发布时间：2026-09-11
  • 📱 移动云电脑全量融合：中国移动云电脑保活（SOHO REST 签名加密 + ZTEC CAG TCP 三阶段握手 + SC/ZTE 自适应开机），零 Python 依赖，与天翼云同台统一管理、统一配额。
  • 🛡️ 多账号多机全量保活：单账号名下多台云主机全部纳管保活。
  • 🧩 网格自由排版：账号卡片支持拖拽排序与行内留白放置（允许空位、不产生多余空行），布局状态按用户与平台视图持久化，刷新不走样。
  • 🚫 无感刷新与滚动锁定：全面重构为原地增量数据更新（In-Place Update），后台轮询不再整页重绘，彻底消除"刷着刷着跳回顶部"与操作被打断的问题。
  • 🖥️ 设备硬件规格展示：天翼云与移动云设备统一显示 设备 ID 与核心规格，按官方套餐版本智能映射，双云呈现完全对齐。
  • 👥 多用户体系完善：管理员/普通用户权限彻底解耦，全局调度设置仅管理员可见；每用户独立通知推送渠道（企业微信/钉钉/飞书/Bark 等 8 渠道）、独立头像与配额管理。
✨ v2.0.2 重点特性概览
发布时间：2026-09-09
  • 🛡️ 三位一体防冲突引擎：全面升级握手前置拦截与 Type 119/120 信令监听。当你在 PC 或手机 App 打开云电脑时，后台 10ms 内极速主动避让，绝不互踢！
  • 🖥️ 单账号多云电脑支持：全形态兼容个人独立机、政企桌面池（POOL）与抢占式云电脑，同一账号名下多台机器独立展现、独立电源管理与直通访问。
  • 📱 官方 App 扫码免密一键登录：新增天翼云官方二维码授权登录，手机天翼云 App 扫一扫秒级完成绑定，免输验证码与短信。
  • ⏱️ 智能脉冲保活机制：未开启挂机或今日挂机达标后，系统转入极简脉冲待机，99% 时间释放连接通道给官方客户端。
  • ⚡ 纯协议极致轻量化：彻底剔除 Chromium 重型浏览器依赖，纯原生协议连接，内存仅约 20MB，各类 NAS 极速常驻运行。
